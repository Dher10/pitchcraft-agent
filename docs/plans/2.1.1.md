## Codex verification of PR #8 at 4d536b2 (owner's message of 2026-11-18: merge after fixes)

Same rules: on `v2`, red test first where code changes, the reviewer's PASS, the five suites one by one, push, green CI. No change to `main`, tags or pull requests.

1. **Rewrite on a loopback host.** On `next start -H 127.0.0.1`, `/game/123` and `/game/abc` hung. Cause (Next 16.4.6): `NextURL` turns 127.0.0.1 and [::1] into localhost, so `request.url` and the rewrite destination say localhost while the router compares them with the bound host and proxies the rewrite as external (to `::1`, where nothing listens). The proxy already built the target from `request.url`, so the fix is `skipProxyUrlNormalize: true` in `next.config.ts`: the proxy gets the URL as sent (the router's `initURL`, from the bound host, never the Host header) and the destination is passed on as written. Red: a proxy test with the env the build derives from the config; 127.0.0.1 and [::1] fail, localhost is the control. Proof: `check_release_b_browser.mjs notfound csp targets` against the production build on `http://127.0.0.1:<port>` and `http://localhost:<port>`, and client-side navigation to a game with JavaScript on. The preview behavior (404 with heading and links without JavaScript) must not change.
2. **Encoded ids.** `/game/%3849799` opened game 849799 in 2.1.0 and was a 404. `lib/gameRoute.ts` decodes the segment once before the lookup; an invalid escape (`/game/%E0%A4%A`) is malformed and stays a 404. Red regression tests for both.
3. **picomatch GHSA-fc5q-39xc-vjpf withdrawn by GitHub on 2026-11-18.** `docs/SECURITY.md` keeps the row, marks it withdrawn with the date and keeps why `npm audit` changed; `CHANGELOG.md` and `docs/releases/v2.1.1.md` say: "A picomatch advisory (GHSA-fc5q-39xc-vjpf) reported during this release was withdrawn by GitHub on 2026-11-18." `npm audit` and `npm audit --omit=dev` are run and reported; the release text claims no count.
