# Release 2.1.1 (patch, D68)

Approved by the owner's message of 2026-11-17, after the merge of release 2.1.0 (`main` f06e1bf, tag `v2.1.0`, `main` merged back into `v2` at 336c5da). Work on `v2` under D35: red test first for each item, the reviewer's PASS, the five suites one by one, push, green CI. No change to `main`, tags or pull requests.

1. **Game 404 without JavaScript** (STATUS "Next for 2.1.1", candidate (a)). `proxy.ts` imports the published game ids statically from `public/data/archive/index-2026.json` and rewrites an unknown or malformed `/game/<id>`, with status 404, to a server-rendered route that shows the existing not-found content (the h1 and the recovery links). The CSP and nonce behavior stays as it is, pinned by the existing tests. If the bundled index does not validate, the proxy rewrites nothing and the page's `notFound()` stays the backstop (as for a listed id whose file fails validation). Proof: the production build with JavaScript off, `/game/123` and `/game/abc` return 404 with the heading and the links in the HTML, and a valid game still renders. The 404 status on Vercel is confirmed on the preview.
2. **Calendar range clarity on `/archive`** (owner's feedback: the range is hard to read).
   - Days strictly between the start and the end: with games, background `signal-tint` and a 3 px bottom bar in `signal`; without games, only the bar. Start and end keep their style. Tokens only.
   - Instruction above the grid: "Tap a day to see its games. Tap a second day to see every game in between."
   - Summary below the grid when a day or a range is chosen, next to Clear: "{Mon D}, {n} game|games" or "{Mon D} to {Mon D}, {n} game|games". `n` counts the index rows on the chosen days, whatever the other filters, like the number under each day.
   - Accessible name of a day inside the range: ", in your range" added; start and end keep their words.
   - The strings go into `docs/plans/R4-U.md` 5.4 and the claims into `docs/DATA_CONTRACT.md` 3.3. Works without JavaScript, 44 px targets (`scripts/check_release_b_browser.mjs targets`), 375, 430 and 1280 px.
