## Provider contract and facts

- Keep the report sections/headline/summary interface. Each provider sentence
  is exactly `{"text": "...", "evidence": ["F001", "F002"]}`: no
  model-authored paths, values, replacement facts or extra properties.
- New `agents/fact_table.py`: `build_fact_table(doc)` produces typed rows,
  an identity and a private ID-to-source binding index;
  `resolve_fact_ids(ids, table)` validates membership and returns trusted
  rows/bindings. IDs are deterministic enumerations scoped to this table;
  request/cache identity binds the whole table, case and instrument.
- Writer-visible columns: **id, subject, field, value, scope**. Scope carries
  the existing label and actual `through` date; a scope fact coalesces the
  corresponding scope leaves so one ID supports a complete scope sentence.
  Ordinary values retain their subject, statistic/dimension/pitch and scope.
- Build only from the closed projection. Explicit metadata/non-fact
  exclusions remain; aliases are not invented facts. Cover each citable
  value or declared composite binding exactly, including real zero/null.
- Keep raw provider candidates for audit. Resolve IDs before the existing
  number/entity/label/availability/subject/scope checks. Unknown/malformed
  IDs are hard failures (`W1.fact_id`); unsupported authority is a hard
  failure (`W1.authority`). Closed feedback text lives in the lexicon (D6).
- NLI consumes only rendered, resolved cited facts with subject and scope;
  never raw JSON, uncited table rows or model-supplied premises. Scope text
  carries the cutoff. Model/runtime/renderer/table identity invalidates old
  calibration and score caches. Existing score-only semantics remain.
- A limitation fact has a declared, minimal dependency set from the existing
  label rule: same-owner/dimension flag, count, threshold and missing label.
  The code-owned binding/rendering may include this proof only when all
  conditions are verified. Historical flag/null-label citations can map to
  that declared fact closure where uniquely determined; record every source
  binding. Do not add unrelated facts or infer a baseball-effect cause. This
  is the scope needed to let the supported Hagen Smith/sample cause pass
  while the unchanged `official` sentence remains an accuracy failure.
- Compact the serialized table without dropping facts. Preflight all 20
  dev inputs against the existing 60,000-byte request limit. Do not raise
  security/request limits silently; stop if compliant representation cannot fit.
