PitchCraft v2.1.0: a new look and the pages that let you browse the 2026 postseason, one game at a time. No predictions, no betting.

## What changed since v2.0-a
- A new visual identity (design system v2): the scoreboard look, Big Shoulders Display, one header and footer on every page, light theme.
- `/` in the off season is the season in review: the World Series line score, the top three notable games and how PitchCraft works. In season, the daily view is unchanged.
- `/game/<gamePk>`: one page per game after it was played, with the final score, why it is notable, each starter's final line from the box score, and the report as it was published (or written after the game), labelled by its origin.
- `/archive`: filter by team, pick a day or a range on a calendar, and filter by reason. It is rendered on the server, so every filter works without JavaScript.
- `/notable`: the 30 notable games of the 2026 postseason, with the reasons as filters and a plain list of how games are chosen.
- Every link and button on these pages is a target of at least 44 by 44 px on phones and desktops.
- The archive behind these pages: final results, one file per game, notable duels and the final starter line, built from public MLB data under a fixed request budget (40 games).
- The LLM writer stays off in production; reports are rules-based. The evaluation behind that choice is in `docs/results-planB.md`.

## Security
- Security headers and a nonce-based Content Security Policy; `form-action` allows same-origin forms only, so the filters work without JavaScript.
- Next.js 16.4.6, which fixes GHSA-mfr8-8qww-v76h (not reachable in this app). `npm audit`: 0 vulnerabilities.

## QA
`docs/qa/` in this repository holds every gate report, including the failed ones and how each finding was fixed. For this release:
- the archive data audit (`docs/qa/R4-data-audit-2026-11-14.md`) and the release 3 gate (`docs/qa/QA-release-3-2026-11-07.md`);
- an external audit of the release pull request (five findings: four fixed, one deferred) and a browser QA of the preview deployment (`docs/qa/PR6-external-qa-2026-11-17.md`);
- a clean-context review of every commit and browser checks of nine page states at 375, 430 and 1280 px.

## Known limitation
- An unknown game URL returns status 404, but with JavaScript disabled the page body is empty. Fix planned in 2.1.1.

## Not in this release
- The after-the-game layer (pitches, Game Score, verdicts, answers), team and pitcher pages, Today in season and the Spanish release.
