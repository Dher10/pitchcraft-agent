PitchCraft v2.1.1: two fixes to the pages of 2.1.0. No new pages. No predictions, no betting.

## What changed since v2.1.0
- An unknown or invalid game URL now shows "We could not find that game" and the links back to the archive and the notable games even with JavaScript disabled. It still returns status 404.
- The calendar on `/archive` makes a range easier to read. The days between the start and the end are filled and underlined, a line above the calendar explains how to pick one day or a range, and the line next to "Clear" names the chosen days and how many games they hold, for example "Oct 23 to Oct 28, 5 games".

## QA
`docs/qa/` in this repository holds every gate report. For this release:
- a red test before each fix and a clean-context review of every commit;
- browser checks against the production build, with JavaScript disabled, of the 404 for an unknown and an invalid game id and of a valid game page;
- browser checks of nine page states at 375, 430 and 1280 px: every link and button is at least 44 by 44 px and no page scrolls sideways.

## Not in this release
- The after-the-game layer (pitches, Game Score, verdicts, answers), team and pitcher pages, Today in season and the Spanish release.
