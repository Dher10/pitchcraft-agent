PitchCraft v2.2.0: a page size choice on the archive and a site icon that browsers can find. No new pages. No predictions, no betting.

## What changed since v2.1.1
- The archive at `/archive` lets you choose how many games each page shows: 10, 20, 50 or All. It shows 20 by default; before, it showed 50. The choice is a row of links under the count, "Games per page", and the current size is marked. It works without JavaScript. The choice is in the address (`per=10`, `per=20`, `per=50` or `per=all`), so a link keeps it, and changing it keeps your team, days and reasons and takes you back to the first page. Any other value is ignored.
- When the list has more than one page, the count now says which games the page shows, for example "Showing 21 to 40 of 40 games, newest first". When everything fits on one page it reads as before, for example "Showing 5 of 40 games, newest first".
- `/favicon.ico` now returns the site icon, the same mark as the icon the pages already used, in 16 and 32 pixels. Before, browsers that ask for that address got a "not found" response.

## QA
`docs/qa/` in this repository holds every gate report. For this release:
- a red test before each change and a clean-context review of every commit;
- browser checks against the production build, with JavaScript disabled, at 375, 430 and 1280 px: every link and button on the archive pages, including the page size links, is at least 44 by 44 px and no page scrolls sideways;
- the archive team form still submits with JavaScript disabled with no Content Security Policy violation, and a test confirms that the form carries the page size;
- `/favicon.ico` returns the icon file with the same restrictive Content Security Policy as the other static files.

## Not in this release
- The after-the-game layer (pitches, Game Score, verdicts, answers), team and pitcher pages, Today in season and the Spanish release.
